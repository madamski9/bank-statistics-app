# Offer a this-phone-only mode

Cloud synchronization is opt-in. After onboarding, and again after local data is cleared, each device asks once whether to synchronize, explaining that synchronization provides multi-device access and recovery after a lost phone. Until the user answers, the device keeps everything local, and the user can change the choice per device at any time. While it is off, the device neither registers for nor performs synchronization. The user may also delete the cloud copy of transactions, Financial Accounts, Custom Categories, and Events; the device then forgets its synchronization ledger so that turning synchronization back on uploads everything again. Other signed-in devices are unaffected and may keep synchronizing. The local SQLCipher database also holds every other document the application persists (Financial Accounts, the synchronization ledger, Custom Categories, Events), replacing plain JSON files, which are migrated and deleted on first read.
