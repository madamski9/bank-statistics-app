# Offer a this-phone-only mode

Cloud synchronization stays on by default because it provides multi-device access and recovery after a lost phone, but a user can turn it off per device. While it is off, the device neither registers for nor performs synchronization. The user may also delete the cloud copy of transactions, Financial Accounts, Custom Categories, and Events; the device then forgets its synchronization ledger so that turning synchronization back on uploads everything again. Other signed-in devices are unaffected and may keep synchronizing. The local SQLCipher database also holds every other document the application persists (Financial Accounts, the synchronization ledger, Custom Categories, Events), replacing plain JSON files, which are migrated and deleted on first read.
