## App Review Information

Sign-in required: yes. Demo account: not needed, the reviewer signs in with their own Apple Account through Sign in with Apple.

### Notes

```
BankStats builds spending statistics from the notifications of Polish banks (Millennium, PKO BP, ING, mBank) and Apple Wallet. It never connects to a bank and never asks for bank credentials.

Automatic capture needs a Polish bank account, iOS 27 or later and a Shortcuts automation that passes the notification to the app's App Intent. A reviewer will not have these, so the rest of the app can be reviewed without them:

1. Sign in with Apple.
2. In onboarding, choose "Skonfiguruję później" (Set up later) or "Kontynuuj bez odczytywania" (Continue without capture) to skip the Shortcuts setup.
3. Add transactions by hand with "Dodaj transakcję" (Add transaction). The overview, shops, categories, limits and widgets fill from them.
4. To see the capture pipeline work on the device without a bank, open Settings > Capture ("Przechwytywanie") and run "Sprawdź zapis na tym telefonie" (Check saving on this phone). It saves a synthetic sample through the same parser and encrypted storage.

Premium: the paywall shows monthly and yearly auto-renewing subscriptions with a free trial, purchased in the sandbox. "Przywróć zakupy" (Restore purchases) and "Zrealizuj kod" (Redeem code) are on the same screen, with links to the privacy policy and Apple's standard EULA.

Account deletion: Settings > "Twoje dane" (Your data) > "Usuń konto" (Delete account). It deletes the cloud data, the local data and the sign-in account, and revokes Sign in with Apple.

The app's language follows the device; set the device to English to review it in English.

Contact: contact@bankstats.app
```

## App Privacy

Tracking: **No**. The app has no advertising, no analytics SDK and no data broker, and it does not link its data with third-party data.

Raw notification text is read on the device and is not collected. Data that only stays on the device is not "collected" in Apple's sense, so local transactions without cloud sync are not listed. Everything below is collected only for the purposes shown and is linked to the user's identity.

| Data type | Collected because | Purpose |
| --- | --- | --- |
| Contact Info > Email Address | Sign in with Apple or Google through Clerk (Apple's relay address when hidden) | App Functionality |
| Contact Info > Name | Profile name the sign-in provider shares | App Functionality |
| Financial Info > Other Financial Info | Transactions, accounts, categories and limits stored in Convex when cloud sync is on | App Functionality |
| Purchases > Purchase History | Premium subscription status from RevenueCat and the App Store | App Functionality |
| Identifiers > User ID | Clerk user id, also the RevenueCat app user id | App Functionality |
| Identifiers > Device ID | Installation id used to register and revoke devices | App Functionality |
| User Content > Customer Support | A notification the user chooses to send as a diagnostic report, kept for 90 days | App Functionality |

Not collected: location, contacts, health, browsing or search history, photos, audio, payment card details, crash data, performance data and usage analytics.

## Screenshots

Upload `app-store/screenshots/pl` to the Polish localization and `app-store/screenshots/en` to the English one, in file order, under "iPhone with Dynamic Island (medium display)" (1206 × 2622). App Store Connect scales them for other iPhones.

The six images are slices of one panorama, so the phones continue from one image into the next in the order above. The panorama leaves a 64 px strip between slices for the gap App Store Connect shows between screenshots, so slanted edges line up across it. `app-store/screenshots/index.html` builds it: a three.js iPhone model (loaded from jsDelivr) shows each app screenshot from `website/screenshots` with a clean 9:41 status bar, on the black and coral style of bankstats.app, over one neon spending line that runs across all six images. After changing a headline, a phone's position or a source screenshot, render them again with Google Chrome installed:

```sh
bun scripts/render-app-store-screenshots.ts
```
